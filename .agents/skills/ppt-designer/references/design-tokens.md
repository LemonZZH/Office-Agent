# 设计 Token 库

所有 deck 的 theme.js 从这里取预设或在此规则上逐案生成。统一三角色模型，任何情况下不引入第四个主色相。

## 三角色模型

| 角色 | 用途 | 占比 |
|---|---|---|
| `BG` | 背景（米白/深蓝黑等中性面） | 60–70% |
| `PRIMARY` | 主题色：标题、关键形状、图表主系列 | 25–35% |
| `ACCENT` | 单一强调色：封面大数字、高亮条、下划重点 | 5–10% |

辅角色：`TEXT`（正文，近黑/近白）、`MUTED`（次要信息、来源行、轴线）。
图表需要更多系列色时，用 PRIMARY 的明度梯度（tints/shades），不新增色相。

## 汇报风格预设（清晰高效）

浅色为主，"三明治"结构（深色封面/封底 + 浅色内容页）。

## 高端风格（逐案定制）

不取预设，按以下流程生成：

1. 从主题推导动机：行业（金融→深色金属感 / 消费→材质质感 / 文化→留白东方）、受众、场地（发布会大屏→高对比深色）。
2. 生成 2 个设计方向（各含 BG/PRIMARY/ACCENT/字体/motif 描述），写进 brief.md 供用户选。
3. motif 从签名元素库选一：超大号数字 / 圆角图框 / 细线网格 / 大面积留白 + 单个焦点元素。禁止色条/侧边条/标题下划线。
4. AI 配图（dreamina）：封面与章节页用图，提示词要求"无文字、留白构图、深色调优先"，比例匹配目标区域。

## 硬规则（预设与逐案都必须遵守）

- 三明治或全深色，二选一并贯穿全场；浅色页背景默认纯白或接近纯白，不用米黄。
- 每页一个视觉焦点；图示/图表优先于文字块。
- 全部颜色经 theme.js 常量引用；幻灯片间距统一 0.5" 边距、0.3–0.5" 块间距。
- CJK 行宽给 15% 余量；正文左对齐；标题可居中。
- 粗体文案避免半角 `+`（预览渲染回退成 ✦），用"同比增长/新增/降本"等中文表述；常规体不受影响。
- 禁止：色条/侧边条/标题下划线/彩虹配色/正楷艺术字/emoji 入片。
