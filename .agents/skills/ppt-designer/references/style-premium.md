# 风格预设：高端（逐案定制）

适用：发布会、品牌宣传、重要客户决审、领导汇报。目标是**被记住**。不取现成预设——每个 deck 先设计，再生产。

## 定制流程（区别于其他风格的关键）

1. **动机推导**：从主题提炼情绪关键词（行业、受众、场地：发布会大屏 → 高对比深色；文化题材 → 留白东方）。写进 brief.md。
2. **出设计方向**：生成 **2 个方向**，各含：情绪描述、BG/PRIMARY/ACCENT 色值、字体搭配、motif 选择、封面意象（AI 配图描述）。写入 brief.md；主会话内让用户选，子代理内按场景自选并说明。
3. **AI 配图**（dreamina，消耗积分——**先告知用户预计张数与消耗再执行**）：
   - 封面 1 张 + 章节页/情绪页 1–3 张，内容页仍以原生图表与图示为主
   - 提示词要点：无文字、留白构图、深色调优先、与 ACCENT 色呼应；比例匹配目标区域（封面 16:9 或按 layout）
   - `dreamina text2image` → `query_result --download_dir` 存入 `assets/`；生成失败/积分不足时回退为纯设计封面并说明
4. **逐页节奏**：全片交替"情绪页（大图+少字）—信息页（图表/图示）"，比例约 1:2；信息密度整体低于汇报档。

## 质感规则

- motif 全场唯一且贯穿（超大数字 / 细线网格 / 圆角图框 / 大留白+单焦点，四选一）。
- 字体对比拉大：封面 60pt+，情绪页正文可低至 16pt 但留白充分；层级靠字号与字重，不靠换字体。
- 图表极简：去网格线、去图例（直接标注）、单系列用 PRIMARY 单色 + ACCENT 高亮一项。
- 动效走 animate.py 后处理：慢 fade（600–900ms、大 stagger 250ms+）营造"呼吸感"；情绪页只留一个进场焦点；切换统一 fade slow。禁止弹跳、旋转等廉价效果。
- QA 循环上限 3 轮，每轮只修 visual-judge 指出的问题，不做无据重排。
