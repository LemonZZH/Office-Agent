# 风格预设：汇报（清晰高效）

适用：周/月/季汇报、工作总结、项目复盘、数据同步。目标是**三分钟读明白**，不追求视觉惊艳。

## 选本风格时

配色从 design-tokens.md 的"汇报风格预设"四套中选（默认墨蓝商务）；浅色三明治结构：深色封面/封底 + 浅色内容页。用户偏好冲突时以其为准。

## 结构模板

**工作汇报**：封面 → 本期结论（3 条以内，结论先行）→ 关键进展（时间线/流程图）→ 数据看板（2–4 个大数字 + 1 个主图表）→ 问题与归因 → 下期计划（表格式：事项/负责人/时间）→ 封底

**数据复盘**：封面 → 核心结论 → 指标总览（大数字行）→ 分维度拆解（图表，每图回答一个问题）→ 归因分析（图示）→ 行动项 → 封底

**项目总结**：封面 → 项目回顾（背景+目标达成度）→ 里程碑 → 成果量化 → 经验教训（两栏：做得好/待改进）→ 后续 → 封底

## 版式要点

- 内容页标准骨架：左上标题（30–36pt）+ 下方一个焦点区（图表/大数字/图示）+ 底部来源行（12pt MUTED）。
- 数据页：数字用 ACCENT 色 60pt+，标签 14pt；图表优先条形/折线，去掉网格线噪音，直接标数值。
- 文案纪律：标题写结论（"Q3 营收 +23%，超目标 5pct"），不写名词（"营收情况"）。
- 单页图表 ≤ 2 个；文字块 ≤ 4 行。
- 本风格**不用 AI 配图**：全部原生形状 + 图表，保证生成快、完全可编辑。封面用深色底 + 超大标题 + 细线几何 motif。
